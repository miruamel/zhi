## Perbaikan build script (commit `f32e1d6`)

**Masalah**: `bun run native:build` selalu gagal di environment ini dengan dua akar penyebab:

1. **`-dynamic -rdynamic` ditolak oleh target `wasm32-freestanding`** — Zig 0.14.0 menolak dynamic linking pada freestanding target. Error: `dynamic linking unavailable on the specified target`.

2. **`zig` di PATH adalah ELF strip yang tidak bisa menemukan direktori instalasi sendiri** — `/usr/local/bin/zig` melaporkan version 0.14.0 tapi `build-lib` gagal dengan `unable to find zig installation directory '/usr/local/bin/zig': FileNotFound`. Binary yang berfungsi ada di `/tmp/zig-linux-aarch64-0.14.0/zig`.

**Fix**:
- Hapus `-dynamic -rdynamic` dari `build.sh` (inkompatibel dengan wasm32-freestanding)
- Ganti single `zig` lookup dengan compile-probe loop: coba setiap candidate (PATH zig, lalu `/tmp` extracted binaries), gunakan yang pertama kali sukses compile
- Pindahkan self-diagnose fallback (verify wasm magic, copy dari CWD jika `-femit-bin` diabaikan) setelah probe

**Verifikasi**: `bun run native:build` → `zig: /tmp/zig-linux-aarch64-0.14.0/zig` → `ok: native/out/stream.wasm built (750 bytes)`. Gate: all checks passed (367 pass / 0 fail / 730 expect() across 73 files).

**Residual**: WASM write barrier masih trigger di proot environment — `parseSseWasm` return array kosong, `parseStream` fallback ke TS parser. Ini spesifik environment (dokumentasi di `zigBridge.test.ts`), bukan code bug. CI gunakan Zig 0.16.0 yang proper, seharusnya exercise WASM path.
