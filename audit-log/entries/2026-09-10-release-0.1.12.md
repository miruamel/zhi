## Catatan: duplicate release

Workflow `publish.yml` `Create Release` job awalnya gagal karena release `v0.1.12` sudah ada (dibuat secara manual sebelum workflow berjalan). Diagnosa dari log: `a release with the same tag name already exists: v0.1.12`. Dihapus release manual tersebut, lalu `gh run rerun 34493943417 --failed` — job `Create Release` berjalan ulang dan selesai sukses. Pelajaran: jangan buat release secara manual sebelum workflow `publish.yml` berjalan; biarkan workflow yang membuat release.
