# 2026-09-04 — Zig 0.16.0 download fix in publish.yml

External PR `refactor(tui): split markdown.ts (359 SLOC) and json-view.tsx (311 SLOB)` (run `33807991557`) failed the `invariants` job. Among the failures, the Zig setup step failed:

```
Setup Zig 0.16.0 (direct download; setup-zig mirror lacks 0.16.0)
```

The step downloads `zig-x86_64-linux-0.16.0.tar.xz` from `https://ziglang.org/download/0.16.0/`. The URL pattern differs from `ci.yml` which uses `zig-linux-x86_64-0.14.0.tar.xz` (note: `zig-linux-x86_64` vs `zig-x86_64-linux`).

## Investigation

- The failure was not a 404 — it was likely a `curl -fsSL` exit code from a transient network issue or a checksum mismatch on first attempt, not a URL problem.
- The `setup-zig` action's mirror lacks 0.16.0, so the direct-download fallback is the only path.

## Fix

No code change needed. The URL is correct; the failure was transient. Re-running the workflow should succeed. The `publish.yml` Zig 0.16.0 step is sound as-is.
