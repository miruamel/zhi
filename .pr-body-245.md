## Problem Statement

- #245: `GenerateInput.domain` documented as optional defaulting to `app`, but `generate()` used `input.domain` directly — calling `generate({})` emitted `engine/undefined/index.ts`.

## Approach

- Normalize domain once with `input.domain ?? 'app'` in `generate()`; `generateStream()` delegates to `generate()` so the fix applies to both paths.
- Added regression test: `defaults an omitted domain to app for batch and stream output`.

## Verification

- `bun test engine/build/test/generate.test.ts`: 11 pass, 0 fail.
- No behavior change for callers that already pass `domain`.

Closes #245
