## Judul: refactor(tui): split pane-display + app-render to enforce 150-SLOC gate; fix circular dep

## Problem Statement

- `pane-display.tsx` (157 SLOC) and `app-render.tsx` (207 SLOC) violated the 150-SLOC quality gate.
- dependency-cruiser found a circular dependency: `compose.ts` → `run-critic/index.ts` → `compose.ts`.
- `src/tui/core/app/render/` orphaned directory with stale `app-render.tsx` (198 SLOC) and `app-render-top.tsx` (52 SLOC) — dead code after the split.

## Approach

1. **Pane split**: `pane-display.tsx` → 6 focused files under `src/tui/panes/` (status, log, input, chart, tree, grid). Barrel `index.tsx` re-exports.
2. **app-render split**: `app-render.tsx` (207) → thin wrapper (52 SLOC) + `app-render-panes.tsx` + `app-render-panes-metrics.tsx` (101 SLOC). Metrics panes (dashboard, release, orch, budget, loop, sessions, memory, config, help) extracted to `app-render-panes-metrics.tsx`.
3. **Circular dep fix**: Inlined `CruiserReport` type in `run-critic/index.ts` to break the type-only back-edge; `compose.ts` retains the exported type for consumers.
4. **Orphan cleanup**: Deleted `src/tui/core/app/render/` directory; updated `src/tui/app.tsx` import path from `core/app/render/app-render` to `core/app/app-render/app-render`.
5. **dependency-cruiser**: `dependency-cruiser.config.cjs` with 4 rules (engine→src, src→native, native→engine|src, deep-relative-import). Run passes clean: 266 modules, 380 dependencies, 0 violations.

## Files Changed

- Deleted: `src/tui/panes/pane-display.tsx`, `src/tui/core/app/render/app-render.tsx`, `src/tui/core/app/render/app-render-top.tsx`
- Added: `src/tui/panes/{status,log,input,chart,tree,grid}-pane.tsx`, `src/tui/core/app/app-render/app-render-panes.tsx`, `src/tui/core/app/app-render/app-render-panes-metrics.tsx`
