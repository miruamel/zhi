## Problem Statement

- ADR-017 M2 scope = "Knowledge" milestone for v0.1.14.
- `engine/knowledge/` exists with a vector store and `engine/loop/observability/logger.ts` records transitions, but there is no TUI pane exposing knowledge: no way to browse facts, inspect embeddings, or query the vector store from the UI.
- `MemoryPane` (`src/tui/panes/middle/memory/memory.tsx`) renders `memoryFacts: Fact[]` — a flat key/value list with no search, no filtering by tag, no pagination.
- Impact: knowledge is write-only from the TUI perspective; users cannot inspect or query what the agent has learned.

## Approach

1. **Add `MemoryPane` search + tag filter** — text search across key/value, tag chip filter, empty state. Reuses existing `Fact[]` and `Badge` widget.
2. **Add knowledge vector-store inspection** — new `KnowledgeInspector` component rendering: fact count, embedding dimension, top tags by frequency, and a search box that queries the vector store (via a new `engine/knowledge/query.ts` helper returning `Fact[]` ranked by cosine similarity).
3. **Wire into `AppRenderPanesMetrics`** — pass `memoryFacts` + new knowledge state through the existing `memory` pane block; add a `knowledge` PaneId + layout entry + constraint.

## Alternatives Considered

- **Defer knowledge UI to M5 (Extensibility, v0.3.0)**: rejected — ADR-017 places knowledge in M2; deferring leaves M2 empty and delays the only user-facing knowledge surface.
- **Replace `MemoryPane` with a full vector-DB admin UI**: rejected — scope creep; M2 is "knowledge" not "vector DB management". Start with inspection + search.
- **Server-side query only, no UI**: rejected — TUI is the primary interface; knowledge must be browsable.

## Risks & Mitigations

- `engine/knowledge/` API surface unknown — mitigated by reading it before implementing; if no query helper exists, add a minimal one (`query(facts, embedding, topK)`) rather than wiring raw vector math into the UI.
- `MemoryPane` SLOC growth — mitigated: current ~60 lines; search/filter adds ~30 → ~90, under 150 cap.
